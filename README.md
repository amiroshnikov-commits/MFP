# Outlook Unanswered Mail Scanner

Небольшой CLI-скрипт для Windows, который сканирует ваш Inbox в MS Outlook и показывает письма, на которые вы, вероятно, ещё не ответили.

## Как это работает

Скрипт:
1. Считывает письма из **Sent Items** за последние `N` дней.
2. Собирает `ConversationID` диалогов, в которых есть отправленные вами письма.
3. Сканирует **Inbox** за те же `N` дней.
4. Исключает письма:
   - отправленные вами,
   - уже помеченные Outlook как Reply/Reply All/Forward,
   - из диалогов, где уже есть ваше письмо в Sent Items.

Оставшийся список выводится как «неотвеченные».

## Требования

- Windows
- Установленный и настроенный Microsoft Outlook (Desktop)
- Python 3.9+
- Пакет `pywin32`

## Установка

```bash
pip install pywin32
```

## Запуск

```bash
python unanswered_outlook.py --days 30 --limit 50
```

Параметры:
- `--days` — глубина сканирования в днях (по умолчанию `30`)
- `--limit` — сколько писем показать (`0` = показать все)

## Примечания

- Точность зависит от корректности `ConversationID` и структуры вашей переписки.
- Если работаете с несколькими ящиками/общими mailbox, можно доработать скрипт для конкретного Store.
